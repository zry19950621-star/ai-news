给长上下文推理省算力：TokenGate 学会剪掉不重要的输入 token

TokenGate: Adapting LLMs for Fast and Memory-Efficient Prefill with Learned Token Pruning

新闻事实 TokenGate 是一个可插拔的小组件：长提示的成本大头在预填充，即模型开始生成前先读完整个提示的过程，模型要把每个输入 token 逐层算一遍，还要缓存以后可能用不上的键值。TokenGate 用可学习的 token 剪枝决定哪些 token 值得完整处理。作者报告，首 token 延迟快了 1.4 至 11.3 倍，峰值内存低了 1.5 至 3.4 倍，且预填充精度没有下降。 信源评级 A。论文原文，10 月 25 日出现媒体解读。 注意点 11.3 倍是作者报告的区间上限，来自针尖测试条件，不是通用业务文档的规划数字；预印本未经同行评审。长上下文推理的成本优化，直接决定大模型跑长文档、长代码库的账单。
